# 생각 한글 요약

에이전트의 생각(대부분 영어)을 대화창 **작업 과정** 제목 아래에 💭 한글 한두 줄로 요약해 보여 주고, 보통 안 봐도 되는 도구 카드(bash 등)는 숨깁니다.

## 동작
- 플러그인을 켠 **이후**에 나온 생각만 요약합니다(이전 대화는 그대로).
- 작업 과정이 접혀 있어도 요약이 보입니다. 생각이 많으면 최근 4개만 보이고 "이전 생각 N개 더 보기"로 펼칩니다.
- 요약이 붙은 작업 과정에서는 영어 원문 블록을 숨기고, 각 줄의 **원문** 버튼으로 다시 볼 수 있습니다.
- 숨기는 도구 카드(기본): bash, eval, read, grep, glob, find, ls, todo, wait. 파일 수정(edit·write) 카드는 그대로 보입니다.

## 요약 방식
- 별도 탭 없이 백그라운드에서 `omp -p`(도구·스킬·세션 끔)로 빠른 모델에 요약을 맡깁니다. 한 번에 약 5~6초.
- 같은 생각은 다시 요약하지 않고(캐시), 화면에 보이는 것만 요약합니다. 생각마다 짧은 모델 호출 1번이 들어가므로 사용량이 조금 늘어납니다.
- `omp` CLI가 설치되어 있고 요약 모델 계정이 로그인되어 있어야 합니다.

## 설정 (설정 → 플러그인 → 생각 한글 요약)
켜기/끄기, 요약 모델(기본 `claude-haiku-4-5`), 숨길 도구 목록, 영어 원문 블록도 보이기.

> 앱 내부 화면 구조를 읽어 동작하므로, 앱 업데이트로 구조가 바뀌면 요약이 안 뜰 수 있습니다.
